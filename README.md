# 🎛 Reminder Telegram Bot — «Напоминалкин» (Single-Message UI + Telegram Mini App)

Асинхронный Telegram-бот для управления персональными разовыми и повторяющимися напоминаниями, работающий в двух синхронизированных режимах поверх единой базы данных SQLite:

1. **Чат-режим (Single-Message UI — «Одноэкранный пульт»)** — работает как служба `systemd` (`reminder_bot.service`), не требует открытия входящих портов и подходит даже при работе Telegram через MTProto-прокси.
2. **Telegram Mini App** — адаптивный веб-интерфейс (FastAPI + нативный JS/CSS под тему Telegram), развёрнутый в Docker Compose и опубликованный по HTTPS через **Cloudflare Tunnel**.

---

## ⚙️ Технологический стек

* **Python 3.12+**
* **aiogram 3.x** (Telegram Bot API, FSM, Inline-клавиатуры, пакетное удаление сообщений, HTML-разметка, персональная кнопка `MenuButtonWebApp`)
* **aiohttp-socks** (опциональная маршрутизация запросов к Telegram API через SOCKS5/HTTP-прокси)
* **FastAPI + Uvicorn** (REST API и статика для Telegram Mini App)
* **SQLAlchemy 2.0 (Async) + greenlet + aiosqlite** (единая SQLite БД, `NullPool`, `PRAGMA journal_mode = WAL`, `PRAGMA cache_size = -2000`, `PRAGMA busy_timeout = 5000`)
* **Docker Compose + `cloudflare/cloudflared`** (изолированный запуск Mini App и публикация по HTTPS без reverse proxy и локальных SSL-сертификатов)
* **python-dotenv** (загрузка конфигурации из `.env`)

## 🧠 Логика работы бота

### 1. Архитектура Single-Message UI и очистка чата (`/clear`)
* В чат-режиме взаимодействие организовано внутри **одного главного сообщения-табло**, которое обновляется на месте (`edit_message_text`).
* На главном экране отображается текущее локальное время и дата пользователя (`Сейчас ЧЧ:ММ, Д месяца ГГГГ`), кнопки разделов и кнопка **«📱 Открыть Mini App»** (внизу под «⚙️ Настройки»).
* Навигационные кнопки разделов расположены вертикально, а для интерактивных элементов (календарь, выбор часов, барабан минут, сетки номеров напоминаний и пользователей, действия в уведомлениях) используются компактные сетки.
* Любые текстовые сообщения, вводимые пользователем (текст напоминания, даты, время, номера, Telegram ID, имена, команды), мгновенно считываются и удаляются ботом (`delete_message`).
* При переходе между крупными разделами и по командам `/start`, `/menu` и `/clear` выполняется **мгновенная пакетная очистка чата** одним запросом (`delete_messages`).
* Внутри разделов `/reminders`, `/users` и `/user` переключение режимов выбора номера для редактирования/удаления, возврат по кнопке «⬅️ Назад», Reply-редактирование и удаление отдельных напоминаний выполняются **на месте без очистки чата**.
* `AccessControlMiddleware` подключён как `outer_middleware` (до FSM-фильтров) с по-пользовательской блокировкой `asyncio.Lock` и автоматическим сбросом буфера отмены удаления `_LAST_DELETED_REMINDERS`.

### 2. Telegram Mini App
* Доступен **всем зарегистрированным пользователям** бота двумя способами: через кнопку **Mini App** слева от поля ввода (`MenuButtonWebApp`, назначается персонально через `set_chat_menu_button`) и через кнопку **«📱 Открыть Mini App»** в главном меню `/start`.
* **Авторизация и безопасность:** каждый запрос к `/api/*` проверяет подпись Telegram `initData` по `HMAC-SHA256` с токеном бота (срок жизни сессии — 24 часа) и наличие пользователя в `bot_users`. Посторонние и удалённые пользователи получают `401`/`403`, а при удалении участника его кнопка `Menu` сбрасывается на обычные команды.
* **Навигация (нижняя панель):** **«👥 Люди»**, **«🔔 Уведомл.»** (со счётчиком непрочитанных), **«📋 Напоминания»**, **«⚙️ Настройки»**, **«ℹ️ Инфо»**.
* **Полный функционал бота:**
  * **Напоминания:** группировка по тем же горизонтам, создание и редактирование в модальном окне с быстрыми кнопками дат (выбранная кнопка подсвечивается синим), выбором периодичности (`1️⃣ Один раз` и повторы) и мгновенным удалением с кнопкой отмены «↩️ Отменить».
  * **Уведомления:** кнопки «🔁 Повторить», «⏳ Отложить» (`5 мин`, `30 мин`, `1 час`, `1 день`) и «✅ Прочитано» (до нажатия все кнопки нейтральные, при выборе подсвечиваются синим). После обработки уведомления в Mini App модуль `webapp/tg_sync.py` сразу удаляет соответствующее сообщение в чате Telegram (а при сетевом сбое передаёт его ID боту через `tracked_messages`).
  * **Люди:** администратор видит вкладки `Все / Мои / От других` и управляет всеми не-админами; обычный пользователь может приглашать новых участников и редактировать/удалять только тех, кого пригласил сам (с отправкой приветствия новичку и уведомления администратору).
  * **Настройки:** текущее время и часовой пояс, кнопка «📱 Взять пояс с устройства», ручная синхронизация по времени `ЧЧ:ММ` и список пресетов городов.
  * **Инфо:** справочные карточки (включая «📱 Вид приложения») с кликабельными ссылками на `@userinfobot`, контакт разработчика (`openTelegramLink`) и репозиторий GitHub (`openLink`).

### 3. Контроль доступа и управление пользователями (`/users`, `/user`, `/settings`)
* При первом запуске стартовые администраторы и пользователи инициализируются из переменных `ADMIN_TELEGRAM_ID` и `USER_TELEGRAM_ID` файла `.env` в таблицу `bot_users`.
* Если пользователя нет в базе данных и он нажимает `/start`, бот отвечает: **«У Вас нет доступа к боту»**.
* **Приглашение новых пользователей доступно всем участникам** (через `/settings` → «➕ Добавить нового пользователя» или вкладку «Люди» в Mini App):
  * Запрашивается числовой **Telegram ID** (можно узнать через `@userinfobot`) и **имя пользователя**; дубликаты блокируются.
  * Новому участнику отправляется приветственное сообщение с инструкцией и сразу назначается кнопка **Mini App**.
  * Если нового участника добавил обычный пользователь, **администратору приходит уведомление** с кнопкой **«Ok»** (удаляет алерт при нажатии).
* **Редактирование и удаление в `/users` и `/user`:**
  * Сетка номеров `1–15` (свыше 15 — пагинация `⬅️`/`➡️`) подменяет кнопки на месте без очистки чата; номер или Telegram ID можно отправить и текстом.
  * Удаление пользователя проходит через подтверждение (**«✅ Да, удалить»**), после чего удалённому участнику отправляется уведомление о прекращении доступа, очищаются его сообщения и сбрасывается кнопка `Menu`.
* **Персональный раздел `/user`:** открывается для обычных пользователей после приглашения хотя бы одного участника; отображает только приглашённых ими пользователей.
* **Раздел `/users` (только для администратора):** просмотр «Мои пользователи» (с датой добавления) и «Все пользователи» (с датой добавления и пригласившим), добавление, переименование и удаление любого участника (кроме администраторов).

### 4. Создание напоминаний
В чат-режиме напоминание создаётся кнопкой **«➕ Создать напоминание»**, отправкой текста напрямую в чат или **пересылкой сообщения из любого чата/канала** (поддерживаются текст, подписи, документы, фото, видео, голосовые, аудио, видеосообщения, контакты, геолокация и опросы):
1. **Текст напоминания** («✍️ Создание напоминания – Шаг 1 из 4»).
2. **Выбор даты** («📅 Создание напоминания - Шаг 2 из 4»):
   * Быстрые кнопки: **«Сегодня»**, **«Завтра»**, **«Через неделю»**, **«Через месяц»**, **«Через год»**.
   * **«📅 Календарь»** — блокировка прошедших дат, выделение сегодня (`[𝟏𝟗]`), жирные выходные `𝐂б`/`𝐁с`, быстрый переход **«⏩ На год вперёд»** и ручной ввод (`ДД.ММ.ГГГГ` или `ДД.ММ`).
3. **Выбор времени** (двухшаговый):
   * **Час:** умная кнопка быстрого выбора (`15:00` или округлённое `+2 часа` после `14:30` сегодня), сетка `00–23` с блокировкой прошедших часов или ручной ввод `ЧЧ:ММ`.
   * **Минуты:** интерактивный барабан (`▲`/`▼`) и сетка с шагом 5 минут.
4. **Периодичность:** **«Один раз»** или **«🔁 Повторяющееся»** (**«Каждый день»**, **«Раз в неделю»**, **«Каждые две недели»**, **«Ежемесячно»**, **«Ежегодно»**).

### 5. Просмотр, группировка, редактирование и удаление напоминаний (`/reminders`)
* Активные напоминания группируются по срокам срабатывания (заголовки выводятся только для непустых интервалов):
  * **«Сегодня, `<день недели>`, `<число>` `<месяц>` ⏰»** — на сегодня;
  * **«Завтра, `<день недели>`, `<число>` `<месяц>` 🕰»** — через 1 день;
  * **«Послезавтра, `<день недели>`, `<число>` `<месяц>` 🕑»** — через 2 дня;
  * **«Совсем скоро ⌛️»** — через 3–6 дней;
  * **«Через неделю 📅»** — через 7–13 дней;
  * **«В скором будущем ⏳»** — промежуточные интервалы (14 дней – 1 месяц и 3 – 6 месяцев; выводятся при наличии других именованных групп);
  * **«Через месяц»** — через 1–3 месяца;
  * **«Через полгода»** — через 6–12 месяцев;
  * **«Через год»** — от 12 месяцев и далее.
* **Формат карточек и номера:**
  * В интервалах «Сегодня», «Завтра» и «Послезавтра» выводится только `В ЧЧ:ММ` (плюс периодичность при наличии) и текст напоминания; в остальных интервалах — полная дата с днём недели и временем.
  * Порядковые номера `№1`, `№2`… **скрыты по умолчанию** и появляются на месте на всех карточках только при нажатии **«✏️ Редактировать напоминания»** или **«🗑 Удалить напоминание»**.
  * Кнопки управления прикрепляются напрямую к последнему напоминанию в списке; переключение режимов и пагинация `1–15` выполняются на месте без `/clear`.
* **Быстрое Reply-редактирование:** ответ (Reply / свайп влево) на любую карточку напоминания в `/reminders` мгновенно обновляет её текст на месте без перерисовки списка.
* **Мгновенное удаление и отмена:**
  * Удаление напоминания выполняется **сразу без экрана подтверждения**: удаляется только сообщение выбранного напоминания (и опустевший заголовок группы) без `/clear`; при удалении последней карточки кнопки управления переносятся на предыдущую.
  * Сразу после удаления появляется одноразовая кнопка **«↩️ Отменить удаление»**, восстанавливающая запись (буфер `_LAST_DELETED_REMINDERS` сбрасывается при любом другом действии).
* **Карточка редактирования напоминания:** `✏️ Изменить текст`, `📅 Изменить дату`, `⏰ Изменить время`, `🔁 Изменить периодичность`, `🗑 Удалить напоминание`. После успешного изменения параметров кнопка возврата меняется на **`⬅️ Назад к напоминаниям`**.

### 6. Уведомления и динамический раздел `/notifications`
* Планировщик отправляет лаконичное уведомление (текст, а для повторяющихся — строка `🔁 ...` и текст) с тремя кнопками в ряд:
  * **«🔁 Повторить»** — удаляет уведомление и открывает выбор новой даты и времени;
  * **«⏳ Отложить»** — переносит на **«5 минут»**, **«30 минут»**, **«1 час»** или **«1 день»**;
  * **«✅ Прочитано»** — удаляет уведомление из чата и списка ожидающих.
* Пока есть хотя бы одно непрочитанное уведомление (`pending_notifications`), в главном меню и меню команд автоматически отображается раздел **«🔔 Уведомления» (`/notifications`)**.
* Для повторяющихся напоминаний следующее срабатывание переносится автоматически.

### 7. Раздел «Настройки» (`/settings`) и часовые пояса
* **«🕒 Настроить время бота»** — выбор часового пояса из списка (`London (UTC+1)` … `Магадан (UTC+11)`) или автоматический расчёт сдвига по введённому времени устройства `ЧЧ:ММ` (округление до 15 минут).
* **«➕ Добавить нового пользователя»** — приглашение нового участника по Telegram ID.

### 8. Раздел «Информация» (`/info`)
Для пользователей (кроме администратора; в Mini App доступно всем) доступны 6 справочных карточек:
* **«📋 Как создать напоминание»**
* **«🔔 Работа с уведомлениями»**
* **«🕒 Выбор часового пояса»** (с примером перелёта `Магадан -> Москва -> Уфа`)
* **«👤 Как добавить нового пользователя»**
* **«📱 Вид приложения»** (различия чат-версии и Mini App при работе через VPN и MTProto proxy)
* **«🌐 О приложении»** (open-source репозиторий `REPOSITORY`, контакт разработчика `TgUserName` и автоверсия `ver. X.Y.Z Last update - ДД.ММ.ГГГГ`)

### 9. Оптимизация памяти, надёжность и сеть на VPS
* **SQLite и память:** `poolclass=NullPool`, `PRAGMA journal_mode = WAL`, `PRAGMA cache_size = -2000`, `PRAGMA busy_timeout = 5000`, выборка `LIMIT 100` в планировщике, периодический `trim_memory()` (`gc.collect()` + `glibc malloc_trim(0)`) при старте и раз в 3 часа, `MALLOC_ARENA_MAX=2` в `reminder_bot.service`.
* **Надёжность планировщика:** фиксация `process_triggered_reminder()` выполняется только после успешной доставки или постоянной ошибки (`TelegramForbiddenError` / недоступный чат) с проверкой `expected_remind_at`; ошибки отдельных записей изолированы, реализованы экспоненциальный backoff и обработка `TelegramRetryAfter`.
* **Сеть и прокси:** `AiohttpSession` настроен на IPv4 (`AF_INET`), DNS-кэш 300 с, `keepalive_timeout=120` и поддержку `TELEGRAM_PROXY` (SOCKS5/WARP с `rdns=False`). `sync_user_commands()` кэширует набор команд и состояние кнопки `Menu`, исключая лишние вызовы API.

## 🚀 Установка и запуск на VPS (Ubuntu Linux)

Код проекта размещается в `/opt/reminder_bot`. Чат-бот работает через `systemd` от изолированного пользователя `reminder_bot_user`, а контейнер `reminder_app` запускается с тем же UID/GID (`APP_UID`/`APP_GID`) для бесконфликтной работы с SQLite WAL.

### 1. Подготовка пакетов и пользователя
```bash
sudo apt update && sudo apt install -y python3 python3-venv python3-pip git
sudo useradd --system --no-create-home --shell /usr/sbin/nologin reminder_bot_user
```
*(Для Mini App также должен быть установлен Docker и плагин `docker compose`.)*

### 2. Клонирование и виртуальное окружение для чат-бота
```bash
sudo mkdir -p /opt/reminder_bot
sudo git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git /opt/reminder_bot
cd /opt/reminder_bot

sudo python3 -m venv /opt/reminder_bot/venv
sudo /opt/reminder_bot/venv/bin/pip install --upgrade pip
sudo /opt/reminder_bot/venv/bin/pip install -r /opt/reminder_bot/requirements.txt
```

### 3. Настройка переменных окружения (`.env`)
Создайте `/opt/reminder_bot/.env` в кодировке UTF-8:
```ini
TELEGRAM_BOT_TOKEN=1234567890:AAH_your_bot_token_here
ADMIN_TELEGRAM_ID=123456789
USER_TELEGRAM_ID=987654321,112233445
TZ_OFFSET_HOURS=5
APP_VERSION_PREFIX=1.4
REPOSITORY=https://github.com/YOUR_USERNAME/YOUR_REPO
TgUserName=@YourTelegramUsername

# Опционально: прокси для Telegram API (например, локальный Cloudflare WARP)
# TELEGRAM_PROXY=socks5://127.0.0.1:49000

# Настройки Telegram Mini App и Cloudflare Tunnel
CLOUDFLARE_TUNNEL_TOKEN=eyJ...
WEBAPP_URL=https://reminder.example.com
```

Добавьте UID/GID пользователя `reminder_bot_user` и выставите права:
```bash
grep -q '^APP_UID=' /opt/reminder_bot/.env || echo "APP_UID=$(id -u reminder_bot_user)" | sudo tee -a /opt/reminder_bot/.env > /dev/null
grep -q '^APP_GID=' /opt/reminder_bot/.env || echo "APP_GID=$(id -g reminder_bot_user)" | sudo tee -a /opt/reminder_bot/.env > /dev/null

sudo chown -R reminder_bot_user:reminder_bot_user /opt/reminder_bot
sudo chmod 750 /opt/reminder_bot
sudo chmod 600 /opt/reminder_bot/.env
```

### 4. Настройка Cloudflare Tunnel (для Mini App)
1. В панели Cloudflare (**Networking → Tunnels** / **Zero Trust → Networks → Tunnels**) создайте туннель типа **Cloudflared**, скопируйте токен (`eyJ...`) в `CLOUDFLARE_TUNNEL_TOKEN` файла `.env`.
2. В разделе **Routes → Add route → Published application** добавьте маршрут:
   * **Public hostname:** домен из `WEBAPP_URL` (например, `reminder.example.com`)
   * **Service URL:** `http://reminder_app:8000`
3. Не включайте Cloudflare Access на этот домен (WebView Telegram его не пройдёт — авторизация проверяется на бэкенде). В `@BotFather` ничего настраивать не нужно: кнопка `Menu` назначается ботом персонально только зарегистрированным пользователям.

### 5. Запуск чат-бота (`systemd`) и Mini App (`docker compose`)
```bash
# 1. Чат-бот (systemd)
sudo cp /opt/reminder_bot/reminder_bot.service /etc/systemd/system/reminder_bot.service
sudo systemctl daemon-reload
sudo systemctl enable --now reminder_bot.service

# 2. Telegram Mini App + Cloudflare Tunnel (Docker Compose)
cd /opt/reminder_bot
sudo docker compose up -d --build
```

Проверка работоспособности Mini App:
```bash
sudo docker compose ps
sudo docker compose logs tunnel | grep -i registered
curl -s -o /dev/null -w "GET /: HTTP %{http_code}\n" https://reminder.example.com/
curl -s -o /dev/null -w "API без initData: HTTP %{http_code}\n" https://reminder.example.com/api/bootstrap
# Ожидается: GET / -> 200, API без initData -> 401
```

## 🛠 Команды управления на VPS

### Чат-бот (`systemd`)
* **Статус:** `sudo systemctl status reminder_bot.service`
* **Логи:** `sudo journalctl -u reminder_bot.service -n 50 -f`
* **Перезапуск с восстановлением прав:**
  ```bash
  sudo chown -R reminder_bot_user:reminder_bot_user /opt/reminder_bot && sudo systemctl restart reminder_bot.service
  ```
* **Остановка:** `sudo systemctl stop reminder_bot.service`

### Mini App и туннель (`docker compose`)
* **Статус контейнеров:** `cd /opt/reminder_bot && sudo docker compose ps`
* **Логи Mini App / туннеля:** `cd /opt/reminder_bot && sudo docker compose logs -f reminder_app tunnel`
* **Перезапуск Mini App после правок кода:** `cd /opt/reminder_bot && sudo docker compose restart reminder_app`
* **Пересборка после изменения `requirements-webapp.txt` / `Dockerfile`:** `cd /opt/reminder_bot && sudo docker compose up -d --build`
* **Остановка Mini App и туннеля:** `cd /opt/reminder_bot && sudo docker compose down`

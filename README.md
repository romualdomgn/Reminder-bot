# 🎛 Reminder Telegram Bot — «Напоминалкин» (Single-Message UI)

Асинхронный Telegram-бот для управления персональными напоминаниями, построенный по архитектуре **Single-Message UI («Одноэкранный пульт»)** без использования внешних WebApp/Mini App, доменов и SSL-сертификатов.

---

## ⚙️ Технологический стек

* **Python 3.12+**
* **aiogram 3.x** (Telegram Bot API, FSM, Inline-клавиатуры, пакетное удаление сообщений, HTML-разметка)
* **SQLAlchemy 2.0 (Async) + greenlet + aiosqlite** (асинхронная работа с SQLite, `NullPool`, `PRAGMA cache_size = -2000`)
* **python-dotenv** (загрузка конфигурации из `.env`)

---

## 🧠 Логика работы бота

### 1. Архитектура Single-Message UI и очистка чата (`/clear`)
* Взаимодействие с пользователем организовано внутри **одного главного сообщения-табло**, которое обновляется на месте (`edit_message_text`).
* На главном экране отображается текущее локальное время и дата пользователя (`Сейчас ЧЧ:ММ, Д месяца ГГГГ`).
* Навигационные кнопки разделов расположены вертикально, а для интерактивных элементов (календарь, выбор часов, барабан минут, сетка номеров напоминаний и действия в уведомлениях) используются компактные сетки.
* Любые текстовые сообщения, вводимые пользователем (текст напоминания, даты, время, номера, Telegram ID, имена, команды), мгновенно считываются и удаляются ботом (`delete_message`).
* При переходе из разделов `/reminders`, `/notifications` или окна редактирования, а также по командам `/start`, `/menu` и `/clear` выполняется **мгновенная пакетная очистка чата** одним запросом (`delete_messages`).

### 2. Контроль доступа и приглашение пользователей (`/users`, `/user`, `/settings`)
* При первом запуске стартовые администраторы и пользователи инициализируются из переменных `ADMIN_TELEGRAM_ID` и `USER_TELEGRAM_ID` файла `.env` в таблицу `bot_users`.
* При каждом событии срабатывает `AccessControlMiddleware`. Если пользователя нет в базе данных и он нажимает `/start`, бот выводит сообщение: **«У Вас нет доступа к боту»**.
* **Приглашение новых пользователей доступно всем участникам** (через раздел `/settings` → «➕ Добавить нового пользователя»):
  * Бот запрашивает числовой **Telegram ID нового пользователя** (с подсказкой, как узнать его через `@userinfobot`) и затем **имя пользователя**.
  * Если введённый Telegram ID уже есть в базе, бот предупреждает об этом.
  * Новому участнику отправляется приветственное сообщение с инструкцией по запуску (`Menu` / `Start`), ссылкой на раздел «Информация» и рекомендацией задать свой часовой пояс в «Настройках».
  * Если нового пользователя добавил обычный участник, **администратору приходит уведомление** с именем, Telegram ID нового пользователя, именем пригласившего и кнопкой **«Ok»**, при нажатии на которую сообщение удаляется.
* **Персональный раздел `/user` для пригласивших**:
  * Если обычный пользователь добавил хотя бы одного нового участника, для него в меню команд и на главном экране автоматически открывается раздел **`/user`** («👥 Раздел «Пользователи»»).
  * Доступны кнопки: **«➕ Добавить нового пользователя»**, **«✏️ Редактировать пользователя»**, **«🗑 Удалить пользователя»**.
  * Обычный пользователь видит, редактирует и удаляет **только тех пользователей, которых он создал сам**.
* **Раздел `/users` (только для администратора)**:
  * Кнопки **«Мои пользователи»** (добавленные администратором, с датой добавления) и **«Все пользователи»** (добавленные другими участниками, с датой добавления и указанием пригласившего).
  * Добавление новых участников, редактирование имени и удаление любого пользователя (с отправкой уведомления о прекращении доступа).

### 3. Создание напоминаний
Создать напоминание можно тремя способами: нажав кнопку **«➕ Создать напоминание»**, написав любой текст напрямую в чат или **переслав сообщение из любого другого чата/канала** (поддерживаются текст, подписи к медиа, документы, фото, видео, голосовые, аудио, видеосообщения, контакты, геолокация и опросы):
1. **Текст напоминания** («✍️ Создание напоминания – Шаг 1 из 4»): вводится вручную или извлекается из пересланного сообщения.
2. **Выбор даты** («📅 Создание напоминания - Шаг 2 из 4»):
   * Быстрые кнопки: **«Сегодня»**, **«Завтра»**, **«Через неделю»**, **«Через месяц»**, **«Через год»**.
   * **«📅 Календарь»** — встроенный интерактивный календарь с блокировкой прошедших дат, выделением сегодняшнего дня жирными цифрами (`[𝟏𝟗]`), выделением выходных дней и шапки `𝐂б`/`𝐁c` жирным шрифтом, быстрым переключением года и месяца (**«⏩ На год вперёд»**), а также ручным вводом (`ДД.ММ.ГГГГ` или `ДД.ММ`).
   * После выбора даты в карточке рядом с датой отображается день недели (например, `20.11.2026, пятница`).
3. **Выбор времени** (двухшаговый):
   * **Выбор часа:** умная кнопка быстрого выбора (например, `⏰ Сегодня в 15:00`, `⏰ Завтра в 15:00`, `⏰ Через год в 15:00`, а если сегодня уже после `14:30` — округлённое время `+2 часа`), сетка часов `00–23` с блокировкой прошедших часов за сегодня или ручной ввод `ЧЧ:ММ`.
   * **Выбор минут:** интерактивный барабан (`▲`/`▼` для часов и минут), быстрая сетка минут с шагом 5 минут и кнопка подтверждения `✅ Выбрать ЧЧ:ММ`.
4. **Периодичность**:
   * **«Один раз»** или **«🔁 Повторяющееся»** (**«Каждый день»**, **«Раз в неделю»**, **«Каждые две недели»**, **«Ежемесячно»**, **«Ежегодно»**).

### 4. Просмотр, группировка, редактирование и удаление напоминаний (`/reminders`)
* В шапке панели `/reminders` указывается текущий часовой пояс пользователя.
* Активные напоминания группируются по срокам срабатывания с автоматическими сообщениями-заголовками (выводятся только для непустых интервалов):
  * **«Завтра 🔥»** — напоминания на завтра (через 1 день);
  * **«Послезавтра 🕑»** — напоминания на послезавтра (через 2 дня);
  * **«Совсем скоро ⌛️»** — напоминания через 3–6 дней;
  * **«Через неделю 📅»** — напоминания через 7–13 дней;
  * **«В скором будущем ⏳»** — более поздние напоминания (от 14 дней и далее; выводится, если есть хотя бы одно напоминание в ближайших интервалах от 1 до 13 дней).
  * Если в ближайших интервалах (1–13 дней) напоминаний нет, дополнительные сообщения-заголовки не выводятся.
* Каждое активное напоминание выводится отдельным лаконичным сообщением с порядковым номером, днём недели и эмодзи `🔁` для повторяющихся:
  ```text
  №5 - 25.11.2026, среда, в 15:00
  🔁 Ежемесячно
  Позвонить клиенту
  ```
* В панели доступны кнопки **«✏️ Редактировать напоминания»** и **«🗑 Удалить напоминание»**:
  * Обе открывают **равномерную компактную сетку кнопок с номерами** (например: 6 напоминаний → `3 + 3`, 7 → `4 + 3`, 9 → `3 + 3 + 3`; при количестве больше 15 на первом экране отображаются кнопки `1–14` и `➡️` в конце третьего ряда для перелистывания, а на следующих экранах — `⬅️` и/или `➡️`). Также можно просто отправить номер напоминания в чат.
* Карточка управления напоминанием содержит кнопки:
  * `✏️ Изменить текст`
  * `📅 Изменить дату` («Сегодня», «Завтра», «Через неделю», «Через месяц», «Через год», «📅 Календарь»)
  * `⏰ Изменить время` (сетка часов + барабан минут или ручной ввод)
  * `🔁 Изменить периодичность`
  * `🗑 Удалить напоминание`
  * `⬅️ Назад к напоминаниям`
  * `🏠 В главное меню`

### 5. Уведомления и динамический раздел `/notifications`
* Когда наступает назначенное время, фоновый планировщик присылает уведомление с тремя кнопками в один горизонтальный ряд:
  * **«🔁 Повторить»** — удаляет уведомление и открывает на пульте выбор новой даты и времени для этого напоминания.
  * **«⏳ Отложить»** — предлагает отложить напоминание на **«5 минут»**, **«30 минут»**, **«1 час»** или **«1 день»**.
  * **«✅ Прочитано»** — подтверждает прочтение и удаляет уведомление из чата.
* Все сработавшие уведомления без реакции сохраняются в таблице `pending_notifications`. Пока есть хотя бы одно непрочитанное уведомление, в главном меню и в меню команд автоматически появляется раздел **«🔔 Уведомления» (`/notifications`)**. После обработки всех уведомлений раздел автоматически скрывается.
* Для повторяющихся напоминаний планировщик автоматически переносит следующее срабатывание на день, неделю, две недели, месяц или год вперёд.

### 6. Раздел «Настройки» (`/settings`) и часовые пояса
* Раздел `/settings` доступен всем авторизованным пользователям и содержит кнопки:
  * **«🕒 Настроить время бота»** — выбор часового пояса кнопкой (`London (UTC+1)`, `Калининград (UTC+2)`, `Москва (UTC+3)`, `Самара (UTC+4)`, `Магнитогорск (UTC+5)`, `Омск (UTC+6)`, `Красноярск (UTC+7)`, `Иркутск (UTC+8)`, `Якутск (UTC+9)`, `Хабаровск (UTC+10)`, `Магадан (UTC+11)`) или автоматическая синхронизация по введённому текущему времени с устройства (`ЧЧ:ММ`, с округлением до 15 минут).
  * **«➕ Добавить нового пользователя»** — приглашение нового участника по Telegram ID.

### 7. Раздел «Информация» (`/info`)
Для всех пользователей (кроме администратора) доступен справочный раздел `/info` с карточками:
* **«📋 Как создать напоминание»** — инструкция по созданию, календарю, выбору времени, периодичности, откладыванию и редактированию.
* **«🔔 Работа с уведомлениями»** — описание динамического раздела «Уведомления» для напоминаний, ожидающих реакции пользователя.
* **«🕒 Выбор часового пояса»** — объяснение принципа работы с UTC и практический пример создания напоминаний под разные часовые пояса перед перелётами (`Магадан -> Москва -> Уфа`).
* **«👤 Как добавить нового пользователя»** — подробная инструкция, как узнать `Telegram ID` через `@userinfobot` и пригласить участника.
* **«🌐 О приложении»** — ссылка на open-source репозиторий (`repository` из `.env`), контакт создателя/администратора (`TgUserName` из `.env`) и автоматически обновляемая версия сборки (`ver. X.Y.Z Last update - ДД.ММ.ГГГГ`).

### 8. Оптимизация памяти и стабильности на VPS
* Для SQLite подключён `poolclass=NullPool` и ограничение страничного кэша (`PRAGMA cache_size = -2000`, `PRAGMA busy_timeout = 5000`).
* В планировщике и списках выбираются только необходимые колонки вместо полных ORM-моделей (`LIMIT 100` в цикле планировщика), а фильтрация пользователей выполняется на уровне SQL.
* После инициализации бота и периодически раз в 3 часа вызывается `trim_memory()` (`gc.collect()` + `glibc malloc_trim(0)`).
* В `reminder_bot.service` задана переменная `MALLOC_ARENA_MAX=2` для ограничения числа арен памяти `glibc`.

## 🚀 Установка и запуск на VPS (Ubuntu Linux)

Код бота размещается в `/opt/reminder_bot` и работает от изолированного системного пользователя `reminder_bot_user`.

### 0. Расположение файла службы systemd
Файл `reminder_bot.service` размещается по адресу:
```text
/etc/systemd/system/reminder_bot.service
```

### 1. Подготовка пакетов на сервере
```bash
sudo apt update && sudo apt install -y python3 python3-venv python3-pip git
```

### 2. Создание изолированного пользователя `reminder_bot_user`
```bash
sudo useradd --system --no-create-home --shell /usr/sbin/nologin reminder_bot_user
```

### 3. Клонирование репозитория в `/opt/reminder_bot`
```bash
sudo mkdir -p /opt/reminder_bot
sudo git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git /opt/reminder_bot
cd /opt/reminder_bot
```

### 4. Создание виртуального окружения и установка зависимостей
```bash
sudo python3 -m venv /opt/reminder_bot/venv
sudo /opt/reminder_bot/venv/bin/pip install --upgrade pip
sudo /opt/reminder_bot/venv/bin/pip install -r /opt/reminder_bot/requirements.txt
```

Содержимое `requirements.txt`:
```txt
aiogram>=3.13.0
SQLAlchemy[asyncio]>=2.0.35
greenlet>=3.0.0
aiosqlite>=0.20.0
python-dotenv>=1.0.1
```

### 5. Настройка переменных окружения (`.env`)
Создайте или отредактируйте файл `/opt/reminder_bot/.env` в кодировке UTF-8:
```bash
sudo nano /opt/reminder_bot/.env
```
Пример содержимого `/opt/reminder_bot/.env`:
```ini
TELEGRAM_BOT_TOKEN=1234567890:AAH_your_bot_token_here
ADMIN_TELEGRAM_ID=123456789
USER_TELEGRAM_ID=987654321,112233445
TZ_OFFSET_HOURS=5
APP_VERSION_PREFIX=1.4
REPOSITORY=https://github.com/YOUR_USERNAME/YOUR_REPO
TgUserName=@YourTelegramUsername
```

### 6. Назначение прав доступа пользователю `reminder_bot_user`
```bash
sudo chown -R reminder_bot_user:reminder_bot_user /opt/reminder_bot
sudo chmod 750 /opt/reminder_bot
sudo chmod 600 /opt/reminder_bot/.env
```

### 7. Запуск и автозагрузка через `systemd`
```bash
sudo cp /opt/reminder_bot/reminder_bot.service /etc/systemd/system/reminder_bot.service
sudo systemctl daemon-reload
sudo systemctl enable --now reminder_bot.service
```

## 🛠 Команды управления ботом на VPS

* **Проверка статуса бота:**
  ```bash
  sudo systemctl status reminder_bot.service
  ```
* **Просмотр логов в реальном времени:**
  ```bash
  sudo journalctl -u reminder_bot.service -n 50 -f
  ```
* **Обычный перезапуск бота:**
  ```bash
  sudo systemctl restart reminder_bot.service
  ```
* **Перезапуск после редактирования файлов от `root` (с восстановлением прав):**
  ```bash
  sudo chown -R reminder_bot_user:reminder_bot_user /opt/reminder_bot && sudo systemctl restart reminder_bot.service
  ```
* **Остановка бота:**
  ```bash
  sudo systemctl stop reminder_bot.service
  ```

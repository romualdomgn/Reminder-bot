# 🎛 Reminder Telegram Bot — «Напоминалкин» (Single-Message UI)

Асинхронный Telegram-бот для управления персональными напоминаниями, построенный по архитектуре **Single-Message UI («Одноэкранный пульт»)** без использования внешних WebApp/Mini App, доменов и SSL-сертификатов.

---

## ⚙️ Технологический стек

* **Python 3.12+**
* **aiogram 3.x** (Telegram Bot API, FSM, Inline-клавиатуры, пакетное удаление сообщений, HTML-разметка)
* **SQLAlchemy 2.0 (Async) + greenlet + aiosqlite** (Асинхронная работа с базой данных SQLite)
* **python-dotenv** (Загрузка конфигурации из `.env`)

---

## 🧠 Логика работы бота

### 1. Архитектура Single-Message UI и мгновенная очистка чата (`/clear`)
* Взаимодействие с пользователем организовано внутри **одного главного сообщения-табло**, которое обновляется на месте (`edit_message_text`).
* Все кнопки во всех окнах расположены строго вертикально (одна под другой).
* В карточках и информационных окнах отсутствуют лишние горизонтальные разделители.
* Любые текстовые сообщения, вводимые пользователем (текст напоминания, даты, время, номера, Telegram ID, имена, команды), мгновенно считываются и удаляются ботом (`delete_message`).
* При переходе из раздела `/reminders` или окна редактирования («Создать напоминание», «Назад к напоминаниям», «В главное меню»), а также по команде `/clear` выполняется **мгновенная пакетная очистка чата** одним запросом (`delete_messages`), чтобы сообщения исчезали одновременно, а не по одному.

### 2. Контроль доступа и приглашение пользователей (`/users`, `/user`, `/settings`)
* При первом запуске стартовые администраторы и пользователи инициализируются из переменных `ADMIN_TELEGRAM_ID` и `USER_TELEGRAM_ID` файла `.env` в таблицу `bot_users`.
* При каждом событии срабатывает `AccessControlMiddleware`. Если пользователя нет в базе данных и он нажимает `/start`, бот выводит сообщение: **«У Вас нет доступа к боту»**.
* **Приглашение новых пользователей доступно всем участникам** (через раздел `/settings` → «➕ Добавить нового пользователя»):
  * Бот запрашивает числовой **Telegram ID нового пользователя** (с подсказкой, как найти его через `@userinfobot`) и затем **имя пользователя**.
  * Если введённый Telegram ID уже есть в базе, бот предупреждает, что такой пользователь уже существует.
  * Новому участнику отправляется приветственное сообщение с инструкцией по запуску (`Menu` / `Start`), ссылкой на раздел «Информация» и рекомендацией задать свой часовой пояс в «Настройках».
  * Если нового пользователя добавил обычный участник, **администратору приходит уведомление** с именем и Telegram ID нового пользователя (и именем пригласившего) и кнопкой **«Ok»**, при нажатии на которую сообщение исчезает.
* **Персональный раздел `/user` для пригласивших**:
  * Если обычный пользователь добавил хотя бы одного нового участника, для него в меню команд и на главном экране автоматически открывается раздел **`/user`**.
  * В разделе `/user` доступны кнопки **«Добавить нового пользователя»**, **«Редактировать пользователя»** и **«Удалить пользователя»**.
  * Обычный пользователь видит, редактирует и удаляет **только тех пользователей, которых он создал сам**.
* **Раздел `/users` (только для администратора)**:
  * Полный список всех пользователей бота (имя, Telegram ID, роль), добавление новых участников, редактирование имени и удаление любого пользователя (с отправкой уведомления о прекращении доступа).

### 3. Создание напоминаний
Создать напоминание можно тремя способами: нажав кнопку **«➕ Создать напоминание»**, написав любой текст напрямую в чат или **переслав сообщение из любого другого чата/канала** (поддерживаются текст, подписи к медиа, документы, фото, голосовые и др.):
1. **Текст напоминания**: вводится вручную или извлекается из пересланного сообщения.
2. **Выбор даты**: кнопки **«Сегодня»**, **«1 день»**, **«Неделя»**, **«Месяц»** или **«📅 Ввести дату напоминания»** (формат `ДД.ММ.ГГГГ` или `ДД.ММ`).
3. **Выбор времени**: ввод точного времени в формате `ЧЧ:ММ` или кнопка **«⏭ Пропустить (15:00)»** — напоминание назначается на `15:00` по локальному времени пользователя.
4. **Периодичность**: выбор режима **«Один раз»** или **«Повторяющееся»** (**«Каждый день»**, **«Раз в неделю»**, **«Раз в месяц»**, **«Раз в год»**).
* На каждом шаге создания доступна кнопка **«Обратно»** для быстрого возврата в раздел `/reminders`, если пользователь передумал создавать напоминание.

### 4. Просмотр и редактирование напоминаний (`/reminders`)
* В разделе `/reminders` убраны все значки, эмодзи и жирный шрифт. Каждое активное напоминание выводится отдельным лаконичным сообщением с порядковым номером:
  ```text
  Напоминание №1
  Дата: 20.11.2026
  Время: 15:00 (Мгн)
  Повтор: Один раз
  Позвонить клиенту
  ```
* По кнопке **«Редактировать напоминания»** бот просит ввести порядковый номер напоминания и открывает карточку управления с кнопками:
  * `Изменить текст`
  * `Изменить дату`
  * `Изменить время`
  * `Изменить периодичность`
  * `Удалить напоминание`
  * `Назад к напоминаниям`
  * `В главное меню`

### 5. Действия при срабатывании напоминания
Когда наступает назначенное время, фоновый планировщик присылает уведомление с тремя вертикальными кнопками:
* **«🔁 Повторить»** — удаляет уведомление и открывает на пульте выбор новой даты и времени для этого напоминания.
* **«⏳ Отложить»** — предлагает отложить напоминание на **«5 минут»**, **«1 час»** или **«1 день»**.
* **«✅ Прочитано (скрыть)»** — удаляет уведомление из чата.
* Для повторяющихся напоминаний планировщик автоматически переносит дату следующего срабатывания на день, неделю, месяц или год вперёд.

### 6. Раздел «Настройки» (`/settings`) и часовые пояса
* Раздел `/settings` доступен всем авторизованным пользователям и содержит кнопки:
  * **«🕒 Настроить время устройства»** — выбор часового пояса кнопкой или автоматическая синхронизация по введённому текущему времени с устройства (`ЧЧ:ММ`).
  * **«➕ Добавить нового пользователя»** — приглашение нового участника по Telegram ID.
* Часовые пояса отображаются понятными буквенными сокращениями: `(Мгн)`, `(Мск)`, `(Клд)`, `(Смр)`, `(Омск)`, `(Крс)`, `(Ирк)`, `(Якт)`, `(CET)`.

### 7. Раздел «Информация» (`/info`)
Для всех пользователей (кроме администратора) в меню доступен справочный раздел `/info` с карточками:
* **«Напоминания»** — краткая инструкция по созданию, выбору даты/времени, периодичности, откладыванию и редактированию напоминаний.
* **«Настройки»** — описание того, для чего необходимо задавать часовой пояс устройства.
* **«Добавление нового пользователя»** — подробная инструкция, как узнать `Telegram ID` в боте `@userinfobot` (пересылкой сообщения, через кнопку `User` из контактов или запросом у самого пользователя) и добавить участника в бот.
* **«Общие»** — информация об open-source репозитории бота (переменная `repository` из `.env`) и контакт создателя/администратора для предложений по дизайну и юзабилити (переменная `TgUserName` из `.env`).
* В каждой карточке расположены кнопки **«Назад»** и **«🏠 В главное меню»**.

```text
├── .env.example                # Шаблон файла переменных окружения
├── .gitignore                  # Исключения для Git
├── reminder_bot.service        # Конфигурация службы systemd
└── README.md                   # Документация проекта
```

## 🚀 Установка и запуск на VPS (Ubuntu Linux)

Код бота размещается в `/opt/reminder_bot` и работает от изолированного системного пользователя `reminder_bot_user`.

### 0. Расположение файла службы systemd
Файл `reminder_bot.service` размещается по адресу:
```text
/etc/systemd/system/reminder_bot.service
```

### 1. Подготовка пакетов на сервере
```bash
sudo apt update && sudo apt install -y python3 python3-venv python3-pip git
```

### 2. Создание изолированного пользователя `reminder_bot_user`
```bash
sudo useradd --system --no-create-home --shell /usr/sbin/nologin reminder_bot_user
```

### 3. Клонирование репозитория в `/opt/reminder_bot`
```bash
sudo mkdir -p /opt/reminder_bot
sudo git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git /opt/reminder_bot
cd /opt/reminder_bot
```

### 4. Создание виртуального окружения и установка зависимостей
```bash
sudo python3 -m venv /opt/reminder_bot/venv
sudo /opt/reminder_bot/venv/bin/pip install --upgrade pip
sudo /opt/reminder_bot/venv/bin/pip install -r /opt/reminder_bot/requirements.txt
```

Содержимое `requirements.txt`:
```txt
aiogram>=3.13.0
SQLAlchemy[asyncio]>=2.0.35
greenlet>=3.0.0
aiosqlite>=0.20.0
python-dotenv>=1.0.1
```

### 5. Настройка переменных окружения (`.env`)
Создайте или отредактируйте файл `/opt/reminder_bot/.env` в кодировке UTF-8:
```bash
sudo nano /opt/reminder_bot/.env
```
Пример содержимого `/opt/reminder_bot/.env`:
```ini
TELEGRAM_BOT_TOKEN=1234567890:AAH_your_bot_token_here
ADMIN_TELEGRAM_ID=123456789
USER_TELEGRAM_ID=987654321,112233445
TZ_OFFSET_HOURS=5
repository=https://github.com/YOUR_USERNAME/YOUR_REPO
TgUserName=@YourTelegramUsername
```

### 6. Назначение прав доступа пользователю `reminder_bot_user`
```bash
sudo chown -R reminder_bot_user:reminder_bot_user /opt/reminder_bot
sudo chmod 750 /opt/reminder_bot
sudo chmod 600 /opt/reminder_bot/.env
```

### 7. Запуск и автозагрузка через `systemd`
```bash
sudo cp /opt/reminder_bot/reminder_bot.service /etc/systemd/system/reminder_bot.service
sudo systemctl daemon-reload
sudo systemctl enable --now reminder_bot.service
```

## 🛠 Команды управления ботом на VPS

* **Проверка статуса бота:**
  ```bash
  sudo systemctl status reminder_bot.service
  ```
* **Просмотр логов в реальном времени:**
  ```bash
  sudo journalctl -u reminder_bot.service -n 50 -f
  ```
* **Обычный перезапуск бота:**
  ```bash
  sudo systemctl restart reminder_bot.service
  ```
* **Перезапуск после редактирования файлов от `root` (с восстановлением прав):**
  ```bash
  sudo chown -R reminder_bot_user:reminder_bot_user /opt/reminder_bot && sudo systemctl restart reminder_bot.service
  ```
* **Остановка бота:**
  ```bash
  sudo systemctl stop reminder_bot.service
  ```
